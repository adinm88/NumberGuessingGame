# 🎯 NumberGuessingGame (Tkinter GUI)
This was one of my assignments for DMACC CIS 189 for Module 13. I created a number-guessing game GUI with unit tests that was built with Python and Tkinter. 
The program generates a number between 1 and the user-specified MAX value, and the user must guess it by clicking on numbered buttons. 
Each wrong guess disables that button, while a correct guess triggers a "Winner!" pop-up and resets the game.

This project also includes passing unit tests with the unittest framework in Python.
